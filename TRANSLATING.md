# Translation contributions

The app and website share translation files maintained in the main repository. See [the translation guide](https://github.com/ByteTrainer/trainer-hub/blob/main/locales/README.md).

Portuguese uses the existing URLs. Other languages have their own directories, such as `/en/` and `/es/`. The localized HTML files and copied JSON catalogs in this repository are generated. Submit translation edits to `ByteTrainer/trainer-hub/locales`, then regenerate the site.
